# Spec: Per-run LLM cost (server)

Persist and serve the USD cost of each review run. Cost is produced by
reviewer-core (`ReviewOutcome.costUsd`: real OpenRouter `usage.cost`, else the
injected PriceBook estimate, else null) — zero additional model calls.

## `agent_runs.cost_usd` column

**Data:** `doublePrecision('cost_usd')`, nullable. Re-adds the column dropped
by migration `0009`. No backfill — historical rows stay `NULL` and render "—".

## Run completion

**Component:** `src/modules/reviews/run-executor.ts`
**Behavior:**
- Success → persist `outcome.costUsd` on `agent_runs` and as
  `stats.cost_usd` in the `run_traces` document.
- Failure / cancellation / pre-work fail → persist `null`, never `0`.
- `completeAgentRun`'s `costUsd: number | null` is required, so every call
  site states a value explicitly.

## Contracts

**Data:** canonical in `src/vendor/shared`, mirrored to
`client/src/vendor/shared` in the same commit.
- `RunStats.cost_usd` — `z.number().nullish()`: `run_traces.trace` is frozen
  jsonb; historical documents lack the key and must still parse.
- `RunSummary.cost_usd` — `z.number().nullable()`: always freshly emitted.
- `PrMeta.cost_usd` — `z.number().nullish()`: list-endpoint aggregate.

## PR-list aggregate

**Component:** `src/modules/pulls/routes.ts` (`GET /repos/:id/pulls`)
**Behavior:** one `SUM(cost_usd) … GROUP BY pr_id` query over `agent_runs`
for the listed PRs (same shape as the score aggregate). SQL `SUM` ignores
NULLs and returns NULL when no run has a cost → `cost_usd: null` → "—" in the
UI. Never coerce missing data to `0`.
