# Spec: Per-run LLM cost (client)

Show run cost (USD) on three surfaces. A run without cost data shows "—",
never "$0.00". `$0.00` appears only for a genuinely recorded zero cost
(e.g. a free model).

## `formatCost`

**Component:** `src/lib/cost.ts`
**Behavior:** adaptive precision —
- `null` / `undefined` → `—`
- `>= 1` → 2 decimals: `1.238 → $1.24`, `1 → $1.00`
- `0` → `$0.00`
- `0 < usd < 1` → 2 significant digits, min 2 decimals:
  `0.0013 → $0.0013`, `0.014 → $0.014`, `0.06 → $0.06`, `0.0999 → $0.10`,
  `0.5 → $0.50`
- `< 0.0001` → `<$0.0001`

## PR list Cost column

**Component:** `app/repos/[repoId]/pulls/_components/PRRow`
**Data:** `PrMeta.cost_usd` (sum over the PR's agent runs, from
`GET /repos/:id/pulls`)
**Behavior:** new column between Status and Updated; mono `$0.014`;
null → muted "—". Grid track + `COLUMN_KEYS` + positional cell change
together.

## Timeline tokens · cost

**Component:** `.../pulls/[number]/_components/RunHistory`
**Data:** `RunSummary.tokens_in/tokens_out/cost_usd` (`GET /pulls/:id/runs`)
**Behavior:** completed (`done`) runs only, under the timestamp:
`9,119 tok · $0.0013` (localized thousands separator). Null cost → tokens
only. Failed / cancelled / running → no line.

## Trace drawer COST stat

**Component:** `.../RunTraceDrawer/_components/TraceBody`
**Data:** `RunTrace.stats.cost_usd` (`GET /runs/:id/trace`, nullish —
historical traces lack the key)
**Behavior:** 4th `Stat` tile between TOKENS and FINDINGS; null/absent → "—".
